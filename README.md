# sistemanomina-
Sistema de nómina con pruebas unitarias
# Sistema de Nómina

# Descripción
Sistema de nómina desarrollado mediante programación orientada
a objetos para calcular salarios, bonos, beneficios y deducciones.

# Tecnologías
- Java
- Maven
- JUnit 5
- Git
- GitHub
- Visual Studio Code

# Tipos de empleados
- Asalariado
- Por horas
- Por comisión
- Temporal

## Principios aplicados
- POO
- SOLID
- Encapsulamiento
- Herencia
- Polimorfismo
- Abstracción
- Código limpio
- Refactorización

## Pruebas
Las pruebas unitarias fueron desarrolladas utilizando JUnit 5.

## Metodología
Se utilizó una metodología ágil basada en Scrum.
